# Nokos Mini App

1. Node.js 18+. Tanpa npm install.
2. Edit config.js (API key, token bot, ID Telegram).
3. Jalankan: node server.js
4. Mini App butuh HTTPS: arahkan domain ke server ini, lalu pasang URL-nya di BotFather (Menu Button).

Jangan commit config.js yang sudah berisi key asli ke GitHub.
